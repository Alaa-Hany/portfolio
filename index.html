KinderWorld

An AI-powered learning app for kids. A friendly AI companion — “Kinder” — recommends lessons, tells interactive stories and answers questions, wrapped in full gamification: XP, levels, streaks, badges and achievements, plus daily mood check-ins and learning tracks (Behavioral, Educational and more). The backend passed 3 rounds of technical audit: RBAC, JWT token versioning, field-level encryption and CI/CD — with GPT, Whisper and Stripe.

تطبيق تعليمي للأطفال مدعوم بالذكاء الاصطناعي. رفيق ذكي — “Kinder” — يُرشّح الدروس، ويروي قصصًا تفاعلية، ويجيب عن الأسئلة — مع نظام تحفيز كامل: نقاط خبرة ومستويات وسلاسل أيام وأوسمة وإنجازات، وتتبُّع للمزاج ومسارات تعلّم (سلوكي وتعليمي وغيرها). اجتاز الـ Backend 3 جولات تدقيق تقني: RBAC و JWT token versioning وتشفير الحقول و CI/CD — مع GPT و Whisper و Stripe.

تطبيق ويب بـ Flask يتنبأ بخطورة سرطان القولون من بيانات المريض باستخدام KNN و Naive Bayes و Ensemble (scikit-learn)، مع شريط ثقة لكل نموذج. متعدّد اللغات (عربي · إنجليزي · فرنسي، RTL)، مُهيّأ عبر Docker، ومع PostgreSQL يُخزّن كل تنبؤ.

FAQأسئلة شائعة

Common questions

أسئلة متكررة

Can you add AI to my existing app?هل يمكنكِ إضافة ذكاء اصطناعي إلى تطبيق موجود لديّ؟
Yes — that's a common request. I review the current codebase first, then integrate the AI feature through a clean API layer so your existing app stays stable. نعم — هذا طلب شائع. أبدأ بمراجعة الكود الحالي، ثم أدمج ميزة الذكاء الاصطناعي عبر طبقة API نظيفة كي يبقى تطبيقك الحالي مستقرًّا.
How do you keep API keys and user data safe?كيف تؤمّنين مفاتيح الـ API وبيانات المستخدمين؟
Keys never live in the mobile app — every AI call goes through the backend, with JWT token versioning, role-based access, and field-level encryption for sensitive data. لا تُوضع المفاتيح أبدًا داخل تطبيق الهاتف — كل نداء ذكاء اصطناعي يمرّ عبر الخادم، مع JWT بـ token versioning وصلاحيات RBAC وتشفير على مستوى الحقول للبيانات الحساسة.
Do I get the source code?هل أحصل على الكود المصدري؟
Always. A full repository handover with documentation, an environment setup guide, and a recorded walkthrough. دائمًا. تسليم كامل للـ repository مع التوثيق ودليل تشغيل البيئة وفيديو شرح مسجّل.
What does a typical project cost?كم تبلغ تكلفة المشروع عادةً؟
It depends on scope, so I quote after the scope call — a fixed price with clear milestones, no surprises mid-project. يعتمد على حجم العمل، لذا أقدّم عرض السعر بعد مكالمة تحديد النطاق — بسعر ثابت ومراحل واضحة، دون مفاجآت في منتصف المشروع.
